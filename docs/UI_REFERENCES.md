## Blackboard Ultra

Facts from public guides that the fake BB should mirror:
- Content is added from a **"+" button** on the Course Content page (also inside folders/modules) → **Create** → Folder / Document.
- Creating a folder: type a name (and optional description), then **Done**.
- Ultra Documents are built from **blocks** (text blocks, files, etc.), not one big editor. Our fake keeps one editor per document for simplicity; worth revisiting with real screenshots.
- Folders nest at most **2 levels deep**. Our structure (course → "Module Information" → documents) fits.
- Visibility is set per item (visible / hidden from students).

Sources:
- [Blackboard Ultra: Create and Manage Course Content (Lesley University)](https://support.lesley.edu/support/solutions/articles/4000229762-blackboard-ultra-create-and-manage-course-content-faculty-)
- [Creating and Curating Content in Blackboard Ultra (Fairfield University)](https://fairfield-university.atlassian.net/wiki/spaces/ITSKB/pages/30345240/Creating+and+Curating+Content+in+Blackboard+Ultra)

## SITS / e:Vision

Very little is public. SITS is Tribal's student records system; e:Vision is its web front end. Module screens are typically dense forms and tables. The fake SITS goes for the brief's "old-fashioned institutional" look until we have real screenshots.
